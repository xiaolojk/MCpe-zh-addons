## ✨ 项目简介

本仓库用于收集与整理 **Minecraft 基岩版（Bedrock Edition / MCPE）** 的模组（Add-ons）与插件（Plugins/Scripts）中文汉化资源，目标是：

- 📚 汇总可用的中文本地化文件
- 🛠️ 提供清晰的安装与使用说明
- 🔄 跟进版本更新，持续维护汉化质量
- 🤝 欢迎社区共同完善与纠错

> ⚠️ 本项目仅提供**汉化/本地化相关内容**（如语言文件、文本资源等），不分发原模组/插件的完整付费内容。请支持原作者。

## 🚀 使用方法

1. **找到对应条目**：在上方列表或仓库目录中定位你需要的模组/插件汉化。
2. **下载汉化文件**：进入对应文件夹，下载 `.lang` / `.json` / 文本资源等汉化文件。
3. **备份原文件**：安装前请先备份原模组/插件的语言或文本文件。
4. **替换/导入**：将汉化文件放入对应路径（不同模组/插件结构可能不同，请以条目内说明为准）。
5. **启动游戏验证**：进入游戏检查文本显示是否正常。

> 提示：部分 Add-on/插件更新后可能导致文本 key 变动，如出现缺失翻译欢迎提交 Issue 反馈。

## 🤝 贡献指南

欢迎提交新的汉化或改进现有翻译！

- **反馈问题**：发现错译、漏译或兼容性问题，请提交 [Issue](https://github.com/xiaolojk/MCpe-zh-addons/issues)。
- **提交汉化**：Fork 本仓库 → 添加/修改文件 → 发起 Pull Request。
- **命名建议**：按 `类型/模组名/版本或说明` 组织目录，便于查找与维护。
- **署名与来源**：请注明原模组/插件作者与来源链接，尊重原作者权益。
