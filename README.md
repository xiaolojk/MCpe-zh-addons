## ✨ 项目简介

本仓库用于分享与整理 **Minecraft 基岩版（Bedrock Edition / MCPE）已汉化好的 Add-on / 模组文件**，方便大家直接下载使用。  

- 📦 收录已完成中文汉化的 Add-on 文件（如 `.mcaddon` / `.mcpack` / `.zip` 等）
- 🧩 尽量保留原作品功能，仅对文本与界面内容进行中文本地化
- 🔄 跟进版本更新，持续维护与修正翻译
- 🤝 欢迎反馈错译、漏译或兼容性问题

> 💡 如你有已汉化好的作品想要分享，也欢迎通过 Issue / PR 参与完善。

## 🚀 使用方法

1. 在上方 **收录表** 或 `addons/` 目录中找到需要的汉化作品。
2. 下载对应的 `.mcaddon` / `.mcpack` / `.zip` 等文件。
3. **移动端 / Win10**：通常可直接点击文件用 Minecraft 打开并自动导入；若为 `.zip`，请按原作品说明解压或改后缀后导入。
4. 进入游戏，在 **全局资源 / 行为包** 或 **地图/存档设置** 中启用对应内容（视作品类型而定）。
5. 进入游戏确认中文显示正常。

> 提示：不同 Add-on 的安装方式可能略有差异，请优先参考对应作品文件夹内的说明。若遇到版本不兼容或文本异常，欢迎反馈。
